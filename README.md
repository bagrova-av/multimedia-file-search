# Multimedia File Search Utility (Linux)

Утилита для периодического сканирования директорий на наличие мультимедийных файлов (аудио, видео, изображения) с последующим формированием отчёта в формате JSON.

## Основной функционал

Приложение выполняет рекурсивный обход заданной директории через равные интервалы времени. Найденные файлы группируются по категориям на основе их расширений:
- **Audio**: `.mp3`, `.wav`, `.flac`
- **Video**: `.mp4`, `.avi`, `.mkv`, `.mpg`
- **Images**: `.jpg`, `.jpeg`, `.png`, `.gif`

### Режимы работы
Приложение поддерживает 2 режима вывода данных:
1. **Режим файла (по умолчанию)**: результат сканирования сохраняется в скрытый файл `.media_files` в домашней директории.
2. **Режим Web-сервера (флаг `--web`/`-w`)**: файл на диске не создается. Результаты доступны по сети через GET-запрос по адресу: `http://localhost:1234/media_files`.

## Запуск и использование

### Параметры запуска

Поддерживаемые параметры:
| Короткий ключ | Длинный ключ | Назначение
|----------|----------|----------|
| `-p `| `--path` | Путь к директории для сканирования (по умолчанию: `$HOME`) |
| `-i` | `--interval` | Интервал между сканированиями в секундах (по умолчанию: 10) |
| `-w` | `--web` | Включить режим HTTP-сервера вместо сохранения в файл |
| `-h` | `--help` | Показать справку |

Если один и тот же флаг в CLI дублируется (например, несколько раз `--path`), то актуальным считается значение из последнего флага этого типа.

### Завершение работы
Приложение завершает работу по сигналу `SIGINT` (**Ctrl+C**). При получении сигнала приложение:
1. Останавливает цикл сканирования.
2. Завершает работу HTTP-сервера.
3. Дожидается завершения фоновых потоков (Graceful Shutdown).

### Основные компоненты:
- **`MediaScanner`**- обход файловой системы, фильтрация файлов по типам, генерация JSON-строки.
- **`MediaServer`** - запуск HTTP-сервера в отдельном потоке.
- **`AppConfig`** – объект, хранящий конфигурацию приложения.
- **`utils`** – вспомогательные функции.
- **`main.cpp`** - точка входа и управление жизненным циклом приложения.

## Инструкция по сборке
1. Склонировать репозиторий:
```sh
git clone https://github.com/bagrova-av/multimedia-file-search.git

cd multimedia-file-search
```
2. В корневой директории проекта выполнить:
```sh
# Создание директории сборки
mkdir build
cd build

# Конфигурация и компиляция
cmake ..
# Для сборки в однопоточном режиме:
cmake --build .
# Для сборки в многопоточном режиме:
# N - целое число потоков, используемых при сборке
cmake --build . -jN
```

### Примеры запуска
Запуск сканирования домашней папки с сохранением в файл:
```bash
./MediaScanner
```

Запуск сканирования кастомной папки с сохранением в файл:
```bash
./MediaScanner --path /home/user/Images 
```

Запуск сканирования кастомной папки с выводом в HTTP:
```bash
./MediaScanner -p /home/user/Images -w
```

Запуск сканирования кастомной папки с выводом в HTTP и интервалом 30 сек:
```bash
./MediaScanner --path /home/user/Downloads --interval 30 --web
```
